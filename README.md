# Encar Parser Bot — Car Monitoring from Korea on Encar.com

🤖 Telegram bot: https://t.me/EncarNewParserBot

Telegram bot that tracks new listings on Encar.com — the largest car sales website in Korea. Every minute it checks new cars, converts prices from Korean won to dollars and sends them to a Telegram channel.

## Features
- 🔄 Checks new listings every minute
- 💰 Converts Korean won to USD at current exchange rate
- 🟢 Marks listings under $15,000
- 🔴 Marks listings above $15,000
- 📩 Sends instantly to Telegram channel
